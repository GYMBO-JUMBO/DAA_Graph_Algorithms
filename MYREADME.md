# Graph Algorithms Assignment

This project contains implementations of several graph algorithms for the Design and Analysis of Algorithms course.

Implemented algorithms:

- Disjoint Set Union
- Kruskal algorithm
- Prim algorithm
- Kosaraju strongly connected components
- Topological sort
- DAG shortest paths

The project is written in Java 17.

## Project structure

```text
src/
tests/
tools/
ANALYSIS.md
submission.json
```

Main algorithm implementations are located in:

```text
src/Algorithms.java
```

Additional test cases are located in:

```text
tests/
```

More information about the algorithms, complexity and implementation details can be found in:

```text
ANALYSIS.md
```
